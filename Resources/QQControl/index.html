    第一次使用，从这里开始

    先跑通一次回复，再按需要开启其他功能。

    1. 登录 QQ

      启动 NapCat，在登录页扫码并用手机确认。先在 NapCat 开启 OneBot 正向 WebSocket，记下地址和令牌。

      还没安装？查看 NapCat 安装教程 ↗

    2. 连接账号

      填 OneBot 地址与机器人 QQ 号，保存后展开「配置本次运行的凭证」，填令牌和 DeepSeek API Key，再点「连接并核对账号」。已有可用凭证可留空。

    3. 选谁可以收到回复

      在联系人中添加好友或群，勾选启用，点「保存范围与回复」。群聊默认只在真正 @ 机器人时回复。

    4. 试一次，再正式运行

      点「试运行一次」，让已启用的好友发新消息，或在群里用 @ 选择器选中机器人。确认收到正常回复，再选运行时长并点「开始回复」。

    5. 按喜好加功能

      在「范围与回复」调整性格和字数；图片、插画、定时在「图片与工具」各自配置保存，不用的功能可关闭。

    遇到问题

    连接不上

    确认 NapCat 已登录、OneBot WebSocket 已开启，地址、令牌和 QQ 号都填对。按面板的具体报错处理。

    已连接，为什么不回复？

    连接后还要开始回复。核对会话已勾选并保存、运行未到期、额度未用完。群内用真正 @；主动接话达到条数只做评估，可能选择不接话。到「记忆与记录」查看处理结果。

    怎么修改配置或停止？

    先暂停，再修改并保存，然后重新开始。切换页面会保留草稿；退出应用不保留未保存内容。关闭网页不会停止机器人，需要停止请点「暂停 QQ」。

    凭证会保存吗？

    连接页填写的凭证仅本次进程有效，退出后重填。生图和搜图可选择存入钥匙串；保存失败时按报错处理，不能只看配置保存成功。请勿把凭证或控制链接发给别人。

    微信在哪里？

    微信功能在 macOS 客户端的「微信」目录，仍在测试中。先保存 DeepSeek Key、开启系统权限，再添加并验证会话；Web 暂不提供微信控制。
