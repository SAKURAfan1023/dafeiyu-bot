# Web 与客户端面板迭代

目标：两端均可用、便于理解与操作，配置能够从编辑、校验、保存走到实际运行；状态和错误能帮助用户判断是否生效。以下是持续迭代清单，不以一次构建通过代表全部完成。

## 已发现的具体问题

- Web 发出 `enabled`，但服务端 `save` 分支忽略它，导致勾选范围没有保存，只有开始回复才应用。
- Web 缺少 OneBot 地址和工作时段控件；原生已有对应配置。
- 原生开始按钮总是调用无限时 `start()`，缺少 Web 已有的单次验收和时长选项。
- 回复保存写盘失败时只显示错误，内存配置仍变成新值；现在恢复提交前配置。
- Web 网络请求失败时，结束请求后的重绘可能覆盖错误提示；现在保留本次请求错误。
- 新增分区导航后，页内锚点可能被误当作控制令牌，导致刷新掉授权；现已只接收符合令牌格式的片段，浏览器导航后刷新通过。
- 会话性格回执更新列表时，未保存的勾选范围会被重绘覆盖；现为勾选保留本地草稿，完整跨面板冲突处理待继续。
- Web 多个表单仅在首次读取时填充，原生若干控件直接绑定引擎配置。现已改为独立草稿和版本冲突检查；原生窗口持有草稿，页面重进刷新仅同步未编辑区域。

## 核验方式

仅使用临时数据目录、合成联系人和模拟 OneBot / 模型进行操作测试，不向真实 QQ 会话发送测试消息，不修改当前生产白名单或截止时间。

- `bash scripts/test.sh`：包括范围重新载入、跨午夜工作时段、未知范围拒绝、外部写入冲突回滚。
- `bash scripts/build.sh`：macOS 发布构建与签名检查。
- `python3 scripts/test-control-panel.py '<app executable>'`：隔离真实 HTTP 的鉴权、保存、无效输入和落盘核对。
- Web 浏览器实际编辑 / 点击；原生合成数据渲染与交互分别记录。仅渲染不等于原生操作验收。

后续按以上链路继续，不把本轮补齐的几个控件作为整个目标完成的依据。

## 第二轮验证记录 · 2026-09-29

### 编辑、冲突与页面生命周期

- Web 按连接、范围与回复、插画、生图、识图分别保存草稿。自动状态刷新不覆盖输入；未编辑区域跟随外部更新。配置版本在服务端检查，旧页面不能覆盖新设置；暂停等安全动作不受旧版本限制。
- 两个浏览器页面实际点击：A 将调用限额编辑为 17，B 保存为 31；A 保存被拒且保留 17，显式放弃后显示 31。另一次 B 修改生图设置时，A 的回复草稿 21 保留且可单独保存。该证据来自临时数据目录中的真实 HTTP 服务，不代表真实 QQ 接入验收。
- 原生编辑从直接绑定引擎改为独立草稿。Dashboard 窗口持有 `QQPanelState`，QQ 页面与图片分区重建不再清空草稿；临时输入仅在内存中，成功保存或明确放弃才清除。
- 插画高级画师列表与定时设置一同纳入冲突检测。外部画师更新不能静默替换待提交列表；有草稿时，立即增删画师按钮禁用，并提示先保存或放弃。
- 原生分为连接与运行、范围与回复、图片与工具、记忆与记录四区；开始按钮明确使用已保存设置，未提交草稿另有提示。

## 第三轮验证记录 · 2026-09-29

- Web 与客户端统一为先保存、再开始。Web 的 `start` 仅提交时长和单次模式，服务端拒绝夹带配置修改；连接也只使用已保存地址与账号。未保存的连接输入和回复草稿在网页上得到明确提示，不隐式改写运行配置。
- 只填一半临时凭证会被拒绝；不再忽略单独填写的 OneBot Token 后继续使用旧凭证。接口错误不清空输入。
- 名单增删写盘失败时恢复原名单，避免界面显示成功而磁盘仍保留旧值；重复添加、额度上限与忙碌状态返回明确错误。外部实例写入冲突的添加、移除两条回归均通过。
- 浏览器实点发现操作错误在下次状态轮询时消失，现将本次操作错误保留到下一次操作或明确放弃；真实浏览器跨多个轮询仍能看到提示。
- 更新操作指南及主动接话、回复范围、开始按钮文案，清除旧的“开始时一并保存”说明。

### 验证结果

- Swift 共 133 项测试通过（61 项引擎、72 项核心），其中名单冲突测试包含添加/移除两个参数用例。release 构建和签名检查通过。
- `python3 scripts/test-control-panel.py '<app executable>' --wait-for-expiry` 通过真实本机 HTTP + WebSocket 链路：保存 → 拒绝错误账号/离线 → 合成账号核对 → 添加合成好友 → 保存启用范围 → 开始 → 禁止运行中改范围 → 到期/暂停 → 单次时限 → 持续运行 → 清除临时凭证并断开。普通启动不能携带草稿，失败后配置未改变。
- 一分钟到期是实际等待：到期后模拟 OneBot 仍连接，运行停止、截止清空、队列为零，状态注明达到时限。本轮没有注入消息，因此该条只证明空队列的面板到期路径；非空队列取消由已有引擎回归覆盖，不能混为同一证据。
- 单次模式验证了运行状态与强制 15 分钟截止，未发送消息；“最多一条”的发送行为仍以引擎测试及早期独立证据为准。全链路使用合成身份/凭证、零真实 QQ 连接、零模型请求和发送。
- Web 实际点击验证：未保存账号时连接被拦截，保存合成账号及本机测试地址后刷新仍为原值；显式放弃草稿恢复已保存配置。
- 390×844 浏览器视口检查：文档宽度 390，无横向溢出；状态、暂停、分区导航、错误与草稿提示可读。验证后恢复浏览器尺寸。这不是全表单键盘可访问性验收。

尚未完成：原生真实点击、所有配置字段及依赖状态审计、完整键盘操作、凭证部分保存失败处理，以及发布部署。上述模拟接口证据不等于真实 QQ 或生产部署验收。

## 第四轮验证记录 · 2026-09-29

- 修复连接配置先写钥匙串、后发现配置冲突的问题。连接、生图、识图均先验证并写入普通配置，配置失败时不触碰凭证。

- 另将状态响应延迟 20 秒，验证浏览器显示 10 秒超时与运行待确认；未将超时当成暂停成功。界面与错误文案已检查截图，状态恢复后自动回到同步显示。只使用临时数据、合成账号与本机故障代理，没有连接真实 QQ、读取聊天、请求模型或发送消息。
- 本轮生产改动仅涉及 Web 资源；macOS 重新打包、签名与真实 HTTP 回归通过。未修改引擎和原生客户端逻辑，未把已有 149/150 项引擎结果冒充新增网页交互测试。新增资源的远端检查以本轮提交对应 CI 为准。

结构审查：`renderFreshness` 是状态读取、操作结果与时间变化共同使用的展示边界；使用既有请求序号防止旧结果覆盖新状态，AbortController 只结束浏览器等待，不承担后台事务撤销。没有新增端点、依赖、持久配置或自动重试写入。
