# 命令速查

仅已开启会话、运行期间生效。命令走原有队列与发送额度，**命令本身不调用模型**。群内无需 @。不解析引用、图片附带的命令或 @ 其他人的命令；机器人自身回显不会循环触发。

## 性格

| 命令 | 作用 |
| --- | --- |
| `/persona` 或 `/性格` | 当前性格 |
| `/persona list` | 列表与说明 |
| `/persona 猫娘` | 切换当前会话；也可用英文 ID |
| `/persona default` | 恢复继承默认 |

可选：雌小鬼(teasing)、温柔(gentle)、傲娇(tsundere)、元气(energetic)、理性(calm)、管家(butler)、猫娘(catgirl)、贴吧(tieba)、抽象(abstract)、戏精(drama)。群成员共享群性格；每个好友私聊独立。编号只是浏览标识，不是选择参数。选择会持久化，不抹掉记忆。

## 插画

| 命令 | 作用 |
| --- | --- |
| `/search 白发 猫耳 -黑丝` | 统一关键词搜索，优先满足收藏偏好；无达标候选自动保底 |
| `/search 53325959` | 直接查询作品 ID，不扫描榜单或画师 |
| `/search https://www.pixiv.net/artworks/53325959` | 作品链接查询，仅接受 Pixiv 作品链接 |
| `/id 53325959` | ID 查询的快捷写法 |
| `/hot` | 从日榜第1名按序找可发送新图，不限画师/题材 |
| `/hot 初音未来` | 在榜单候选内筛选 |
| `/next` | 保持上次搜索或榜单条件继续；ID 查询没有下一张 |
| `/next 蓝发 -黑丝` | 替换关键词；上一条是 ID 查询时转为关键词搜索 |
| `/search help` | 完整帮助 |

`/art` 兼容映射到 `/search`，不再提供另一套搜索规则；不带参数显示帮助。`/artist` 和 `/artists` 返回简短迁移提示，不调用模型或来源接口。画师署名继续保留，旧的精选定时画师资料放在面板高级区域。

空格分隔多关键词，`-词` 排除。常见标签有中日英别名映射，不等于任意自然语言语义搜索。Next 不是无限图片保证：无结果、预算用完、来源不可访问会分别提示。没有合格图片不只发作品链接，访问受限不绕过。热度是参考，不保证审美或覆盖完整热门榜单。定时和 Agent 取图共享来源、去重、额度和署名路径。

搜索每轮最多检查 12 个新候选详情，优先公开热门推荐但不声称覆盖完整人气排名。若没有可发送的达标作品，复用本轮详情，按可核验收藏数、点赞数、浏览量选保底图；缺失数据排后并明确说明，不能把缺失当作零。配文显示“保底结果”和实际热度。降级不会修改面板配置，不改变关键词、画质、分级、去重、额度和来源访问规则；空搜索、来源失败、下载失败仍可能没有结果。ID 直查不要求收藏门槛，但其余限制仍有效，失败不会换成别的作品。

## 本次验证（2026-09-29）

- 本机 155 个测试函数通过（82 应用、73 核心）。合成 OneBot 覆盖命令别名、ID/作品链接、保底结果、连续取图、会话隔离、额度、暂停与发送结果未知；命令路径断言零模型调用，Agent 提示词和工具参数同步验证。
- 下载异常共 13 种参数场景通过：缺图、损坏、超限、超时、断连、取消及 HTTP 拒绝等。单次传输最多 20 秒；超时或断连仅尝试该作品详情提供的下一图片地址，全部失败则结束，不继续扫描作品；取消、权限拒绝和限流不走此回退。
- 真实公开来源验证：关键词搜索与同作品 ID 直查共 5 次请求、5.05 秒，结果图片 848393 字节，未调用模型或向 QQ 发送。此前两轮真实下载分别断连、超时，失败证据保留；成功复查不能证明来源始终稳定。
- Release 构建、签名、真实本机 HTTP 配置与运行控制回归通过。浏览器在隔离数据中实际保存优先收藏数 2500，重载仍为 2500；保持暂停、零模型调用和零发送。原生相关字段通过编译，不以此替代原生手动交互验收。

以上分别证明实现、模拟收发、图源访问和配置持久化；不代表真实 QQ 收件人已经验收新版命令，亦不代表 Windows 实机验收。
