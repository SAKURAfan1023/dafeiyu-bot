# 命令速查

仅已开启会话、运行期间生效。命令走原有队列与发送额度，**命令本身不调用模型**。群内无需 @。不解析引用、图片附带的命令或 @ 其他人的命令；机器人自身回显不会循环触发。

## 性格

| 命令 | 作用 |
| --- | --- |
| `/persona` 或 `/性格` | 当前性格 |
| `/persona list` | 列表与说明 |
| `/persona 猫娘` | 切换当前会话；也可用英文 ID |
| `/persona default` | 恢复继承默认 |

可选：雌小鬼(teasing)、温柔(gentle)、傲娇(tsundere)、元气(energetic)、理性(calm)、管家(butler)、猫娘(catgirl)、贴吧(tieba)、抽象(abstract)、戏精(drama)。群成员共享群性格；每个好友私聊独立。编号只是浏览标识，不是选择参数。选择会持久化，不抹掉记忆。

## 插画

| 命令 | 作用 |
| --- | --- |
| `/art` | 精选；默认动漫/游戏美少女主题 |
| `/art 原神` | 直接关键词搜索 |
| `/search 白发 猫耳 -黑丝` | 全站关键词搜索，核验真实收藏数达到配置门槛（默认1000） |
| `/hot` | 从来源日榜第1名按顺序查找可发送新图，不限画师/题材 |
| `/hot 初音未来` | 在榜单候选内筛选 |
| `/artists` | 查看已配置画师 |
| `/artist Anmi 白发` | 画师名加关键词，也支持数字画师 ID |
| `/next` | 保持上次来源和条件继续 |
| `/next 蓝发 -黑丝` | 保持来源，替换关键词 |
| `/art help` | 完整帮助 |

空格分隔多关键词，`-词` 排除。常见标签有中日英别名映射，不等于任意自然语言语义搜索。Next 不是无限图片保证：无结果、预算用完、来源不可访问会分别提示。没有合格图片不只发作品链接，访问受限不绕过。热度是参考，不保证审美或覆盖完整热门榜单。定时和 Agent 取图共享来源、去重、额度和署名路径。
