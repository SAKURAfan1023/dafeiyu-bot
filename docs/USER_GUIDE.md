# 操作指南

## 第一次启用

1. NapCat 扫码成功后，核对面板“预期QQ”与实际账号一致。
2. 选择好友或群白名单，不要一开始启用全部联系人。未启用目标不会自动发送。
3. 填模型 Key、OneBot Token，点击连接；看连接状态、错误提示和账号核对结果。
4. 先选择“单次验收”：让获准好友发新消息，或在群里用真正 @ 选择器选中机器人。确认对端收到后再开始定时运行。
5. 停止请点“暂停”；关闭浏览器不等于停止。截止时间可配置，到期会暂停并清队列。

## 回复、性格和群主动接话

正文默认最多60字，可在面板调整20–200。雌小鬼嘴欠档位仅控制该性格；每会话独立选择优先于全局默认。切换使用 `/persona 名称`，菜单用 `/persona list`。明确说不想互损时风格应收敛，但模型理解并不保证每次正确。

开启“群主动接话”后，每 N 条普通消息（默认10）评估是否值得接话，不保证每10条必发。真实 @、命令和机器人回显不参与普通计数，@不重置计数。主人人工群消息需要 NapCat 上报自己的消息。忙碌时进入有界队列，超时/暂停/额度耗尽时不会无限补发。

## 记忆、主人和引用

每个群、每个好友独立保存。按消息数、字符数或时间积累重点并压缩，面板可查看/管理记忆。记忆可能不准确，可直接纠正，但不要保存密码等秘密。

OWNER 只来自程序核验的本账号人工发言；聊天里自称开发者不会取得权限。私聊会核验双方历史，群引用通过 OneBot 获取原消息。不可取回的引用会标记缺失而不是假装读过。人工接话可能取消已排队的机器人回复，避免抢话。

## 识图、联网和生图

- 识图建议配置智谱视觉 Key；主对话仍由 DeepSeek完成。保留的 DeepSeek 图像路径不意味着所有所选模型都支持图像。
- GIF 按时间抽取最多6帧，单轮最多12帧，并非完整视频理解。
- Google Cloud Vision Web Detection 是可选查图来源能力，需单独项目、API凭证和计费设置；不是直接调用 Google Lens 网页。
- 生图在面板配置智谱主模型和 Cloudflare 备用（Account ID + Token）。服务类失败最多备用一次；审核拒绝不绕过。
- Bing/Wikipedia用于网页信息，Wikimedia用于现有图片；插画使用单独 Pixiv 命令。搜到图片不冒充生成。
- 提供方开通、价格与权限以官方后台为准。关闭不用的功能，可降低费用和延迟。

## 插画与定时

开启插画工具后用 `/art help` 查看。`/search` 可调最低收藏数；`/hot`不限画师和美少女题材，按真实排名寻找可用新图。来源有403/429、缺图或没有权限时跳过，不能只用链接当图片。

面板定时选指定已启用群、每日或每小时、时区和分钟，每次一张。保持机器人运行且未过截止；离线错过的时间不补发。定时依然受日额度、会话范围、去重和来源可用性限制。

## 扩充自己的表情库

公开版自带4张原创示例。将有权使用的 PNG/JPEG/WebP 放入 `Resources/QQStickers/` 并编辑 `manifest.json`，每项包含 `id`、`title`、`emotion`、`file`、`sha256`、`source`、`context`。情绪可选 neutral/joy/smug/annoyed/sad/sleepy/flustered/teasing。`context`描述适用和不适用场景，帮助避免不贴题。

文件需静态可解码、单张≤3MB、尺寸≤4096，路径只能是文件名，ID和内容哈希唯一；用 `shasum -a 256 图片文件` 计算哈希。修改后运行测试与构建。配图没有合适候选时只发文字，24小时内同会话不重复同图片内容；不会因为只有4张而反复强发。

## 暂停、退出、数据

暂停不会删除持久记忆。退出后再启动不会自动开始发送。运行时防止自动休眠，但锁屏不妨碍 OneBot 网络事件；断网、QQ掉线和账号不符仍会停止。不要同时启动两个面板进程。数据目录、外发信息和秘密处理见 [SECURITY](../SECURITY.md)。
