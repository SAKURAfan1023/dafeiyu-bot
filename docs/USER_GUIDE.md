# 操作指南

## 第一次启用

1. NapCat 扫码成功后，填写 OneBot 地址与预期 QQ 号，点击“保存地址与账号”（客户端为“保存连接配置与钥匙串令牌”）。
2. 配置凭证后点击“连接并核对账号”。Web 临时凭证需要同时填写 OneBot Token 和 DeepSeek Key；已有可用凭证可留空。连接只使用已保存地址与账号，核对成功也不会自动回复。
3. 从核对后的联系人列表添加好友或群，勾选允许回复的范围，调整人设、额度与功能开关，再点击“保存范围与回复设置”。未启用目标不会自动发送。
4. 选择“单次验收”：让获准好友发新消息，或在群里用真正 @ 选择器选中机器人。确认对端收到后再选择时长，按已保存配置开始回复。开始不再隐式保存草稿；Web 有回复草稿时会提示先保存或放弃。
5. 生图、识图、插画各自保存。看到“未保存”或“配置冲突”时先处理对应区域；其他页面更新不会覆盖你的草稿。客户端切页保留输入，但退出应用不会保留未提交内容和临时凭证。
6. 停止请点“暂停”；关闭浏览器不等于停止。截止时间可配置，到期会暂停并清队列。
7. 如果钥匙串保存失败，面板会分别说明配置是否已保存、哪些凭证已完成；输入会保留。可修复权限后重试，或在支持的区域取消“保存到钥匙串”，改为仅本次运行。不能把这类部分成功当作全部撤销。

macOS 客户端提供“面板导航”菜单，⌘1–⌘6 依次对应侧栏六个页面，⌘6 为 QQ 接入。切换只改变当前窗口显示的页面，不保存草稿，也不启动托管。

菜单栏助手图标里的“显示面板”会优先恢复已有窗口（包括最小化窗口）；没有可恢复窗口时创建面板窗口，继续使用同一进程的引擎。重新创建窗口时载入已保存配置，关闭前应先保存草稿。显示窗口不等于开始回复；关闭窗口也不等于暂停。

在客户端 QQ 页或菜单栏点击“在浏览器打开 QQ 面板”，网页会控制**当前客户端内的同一个 QQ 引擎**，无需再启动命令行后台。两端共享已保存设置、连接、队列和计数；未保存输入仍留在各自页面，冲突时不会覆盖。反复点击打开会复用同一个入口。

“关闭网页控制入口”会关闭本机端口，使旧页面失去控制权限，**不会暂停 QQ，也不会撤回已经受理的操作**；客户端仍可管理该引擎。再次打开会使用新的入口和令牌。关闭浏览器标签页也不会暂停回复；需要停机时请点击“暂停”。

网页顶部显示最近一次从后台确认状态的时间。读取失败或超过 15 秒没有新状态时，连接与运行标记改为“待确认”，下方计数仅是上次快照；这不代表机器人已停止。此时保留草稿并拒绝普通配置提交，暂停等停止操作仍可尝试。状态请求最多等待 10 秒，操作请求最多等待 60 秒；操作超时不会自动重试，也不代表后台没有执行。等状态恢复后核对已保存配置，必要时放弃旧草稿重新载入；不要因超时反复提交。

## 回复、性格和群主动接话

面板中“启用”勾选与回复参数一起保存；增删会话、切换单会话性格会立即保存。存在未保存的范围或回复草稿时，先保存或放弃，再执行这些即时操作，避免新名单与旧草稿发生冲突。暂停和接管仍可使用。

客户端的每日模型调用、每日发送和单会话每日发送上限支持直接输入整数（1–10000），无需逐次点击加减。输入仅是草稿；在表单末尾保存后才生效，空值、小数或越界会保留供修改并显示错误。修改上限不会重置当天已用计数。

工作时段支持跨午夜，例如 22 点至次日 7 点。关闭限制时保留已保存的起止小时，Web 小时框会禁用；重新开启可继续编辑。启用时不能留空，结束小时不包含在范围内，起止相同表示全天。

正文默认最多60字，可在面板调整20–200。雌小鬼嘴欠档位仅控制该性格；每会话独立选择优先于全局默认。切换使用 `/persona 名称`，菜单用 `/persona list`。明确说不想互损时风格应收敛，但模型理解并不保证每次正确。

开启“群主动接话”后，每 N 条普通消息（默认10）评估是否值得接话，不保证每10条必发。真实 @、命令和机器人回显不参与普通计数，@不重置计数。主人人工群消息需要 NapCat 上报自己的消息。忙碌时进入有界队列，超时/暂停/额度耗尽时不会无限补发。

## 记忆、主人和引用

每个群、每个好友独立保存。按消息数、字符数或时间积累重点并压缩，面板可查看/管理记忆。记忆可能不准确，可直接纠正，但不要保存密码等秘密。

OWNER 只来自程序核验的本账号人工发言；聊天里自称开发者不会取得权限。私聊会核验双方历史，群引用通过 OneBot 获取原消息。不可取回的引用会标记缺失而不是假装读过。人工接话可能取消已排队的机器人回复，避免抢话。

## 识图、联网和生图

- 识图建议配置智谱视觉 Key；主对话仍由 DeepSeek完成。保留的 DeepSeek 图像路径不意味着所有所选模型都支持图像。
- GIF 按时间抽取最多6帧，单轮最多12帧，并非完整视频理解。
- Google Cloud Vision Web Detection 是可选查图来源能力，需单独项目、API凭证和计费设置；不是直接调用 Google Lens 网页。
- 生图在面板配置智谱主模型和 Cloudflare 备用（Account ID + Token）。服务类失败最多备用一次；审核拒绝不绕过。
- Bing/Wikipedia用于网页信息，Wikimedia用于现有图片；插画使用单独 Pixiv 命令。搜到图片不冒充生成。
- 提供方开通、价格与权限以官方后台为准。关闭不用的功能，可降低费用和延迟。

## 插画与定时

开启插画工具后用 `/art help` 查看。`/search` 可调最低收藏数；`/hot`不限画师和美少女题材，按真实排名寻找可用新图。来源有403/429、缺图或没有权限时跳过，不能只用链接当图片。

面板定时选指定已启用群、每日或每小时、时区和分钟，每次一张。保持机器人运行且未过截止；离线错过的时间不补发。定时依然受日额度、会话范围、去重和来源可用性限制。

插画设置有草稿时，先保存或放弃，再单独增删画师；避免即时保存的画师名单与整页草稿互相覆盖。数字框必须填入有效范围内的整数，不能留空代替 0。每小时模式不使用“小时”字段，Web 保存时保留原有每日小时设置；切回每天后可再调整。

客户端的来源请求数、最小尺寸和收藏门槛也保留文字草稿，保存时统一校验；空值、小数或无效格式会报错并保留输入，不会悄悄保存之前的数值。尺寸不设门槛时明确填写 0。

## 扩充自己的表情库

公开版自带4张原创示例。将有权使用的 PNG/JPEG/WebP 放入 `Resources/QQStickers/` 并编辑 `manifest.json`，每项包含 `id`、`title`、`emotion`、`file`、`sha256`、`source`、`context`。情绪可选 neutral/joy/smug/annoyed/sad/sleepy/flustered/teasing。`context`描述适用和不适用场景，帮助避免不贴题。

文件需静态可解码、单张≤3MB、尺寸≤4096，路径只能是文件名，ID和内容哈希唯一；用 `shasum -a 256 图片文件` 计算哈希。修改后运行测试与构建。配图没有合适候选时只发文字，24小时内同会话不重复同图片内容；不会因为只有4张而反复强发。

## 暂停、退出、数据

Web 的“运行记录”和客户端 QQ 页的“记忆与记录”显示最近 30 条处理结果，新记录在前。可查看对应会话、日期和原因，区分时段/额度/主动接话规则跳过、处理失败、发送确认及结果未知。发送确认只表示 OneBot 接受发送，不代表收件人已读；结果未知时不要直接重发。

没有记录时，先检查是否已连接并开始、目标是否勾选且保存、群消息是否真实 @ 或符合主动接话条件。这里不是完整收信流水，不能凭空白断定没有收到消息；历史会话移出名单后显示“当前名单外”。错误摘要限制长度并隐藏当前凭证及常见敏感格式、地址，但面板仍包含会话名称和单独展示的记忆，请勿直接公开整页截图。

暂停不会删除持久记忆。退出后再启动不会自动开始发送。运行时防止自动休眠，但锁屏不妨碍 OneBot 网络事件；断网、QQ掉线和账号不符仍会停止。不要同时启动两个面板进程。数据目录、外发信息和秘密处理见 [SECURITY](../SECURITY.md)。
