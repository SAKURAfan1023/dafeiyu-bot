# v0.2.0-beta.1 · 小红书、人设与话题记忆

2026-10-27。大肥鱼新增与 QQ、微信同级的小红书板块。本次发布为源码公开测试版，适合愿意自行配置、核对草稿和反馈问题的用户。

## 新增能力

- **独立的小红书面板**：扫码登录、核对账号、主题搜索、读取正文与有限评论；原生客户端和 Web 共用配置与引擎，账号、记录和额度单独保存。
- **八种人格与自定义**：大肥鱼、温柔、雌小鬼、傲娇、元气、理性、猫娘、贴吧玩梗；可补充自己的角色 prompt。
- **会补全背景的话题记忆**：按账号、帖子隔离，七天保留、最多 200 个话题；滚动摘要与草稿共用一次模型请求。支持手动校正背景、清除摘要及关闭记忆，未发送草稿不计作实际对话。
- **可核对的评论流程**：生成草稿、编辑确认、指定一级评论回复；也可在任务中选择受限自动参与。额度与发送记录先保存，结果未知时停住，不盲目重发。

## 修正与适配

- 搜索等待真实结果加载，避免把初始化空数组误判成没有匹配。
- 评论区有限等待首批内容，未加载时明确标记；回读只在精确父评论下有限展开。
- 明确 DeepSeek 的思考档位和输出预算，检查截断 JSON；失败时记录已知用量并暂停。
- 原生与 Web 共用人格、记忆及草稿控件，刷新后保留配置。
- macOS 与 Linux CI 固定使用 Node.js 24，执行小红书页面契约检查。
- 修复 Linux 清除话题记忆时的状态访问冲突。
- 为 Linux / WSLg 独立浏览器传递必要的显示连接变量；图形桌面仍需用户自行准备。
- 调整 CI 端口释放检查：任务恢复后再次核对真实 TCP 状态，避免用等待前的旧结果误报。

## 安装与升级

本次提供 GitHub 自动生成的源码包，未提供预编译安装包。macOS 需要 macOS 14+、Swift 6 工具链；小红书另需 Node.js 20+、Chrome，以及自己的模型 API Key。

已有仓库可在项目目录执行：

```bash
git pull --ff-only
bash scripts/setup-xiaohongshu.sh
bash scripts/test.sh
bash scripts/build.sh
```

打开构建出的客户端，进入「小红书 → 账号与连接」扫码、核对并绑定账号，再选择主题、人格和参与方式。默认先写草稿，由你确认；更新不会替用户自动开始任务。

首次使用可下载本页的 **Source code**，或克隆 [GitHub 仓库](https://github.com/SAKURAfan1023/dafeiyu-bot)。Windows 用户按 [WSL2 教程](https://github.com/SAKURAfan1023/dafeiyu-bot/blob/v0.2.0-beta.1/docs/WINDOWS.md) 准备环境，再按 [小红书说明](https://github.com/SAKURAfan1023/dafeiyu-bot/blob/v0.2.0-beta.1/docs/XIAOHONGSHU.md) 配置 Node 与 Linux 浏览器；需要 WSLg 或可用图形桌面，Windows 实机尚未验收。

## 已验证与已知边界

- 本机 174 项 Swift 回归测试通过，页面请求与读取契约检查通过，macOS release 构建和签名校验通过。
- 真实完成登录绑定、搜索、有限读帖、DeepSeek 草稿与摘要生成，以及记忆重启保留。
- 用户授权后只提交过一条真实评论，平台返回新的评论 ID，状态为 `accepted`。页面回读和他人可见性仍未确认，也未确认人类回信；不把平台接受写成完整互动验收。
- 图片、视频主体、折叠的深层楼中楼及全站私信/通知监听尚不支持。微信仍在测试；QQ 已有的私聊、群真实 @ 接收确认与小红书验收分开。
