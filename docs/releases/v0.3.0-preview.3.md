# v0.3.0-preview.3 · 内置 NapCat，QQ 单独下载

首次使用下载大肥鱼客户端，以及同系统的 QQ 原始安装包。大肥鱼包内已含完整 NapCat、Node、QQ 后台和 MCP，无需再寻找 NapCat 下载。

## 下载并开始使用

| 系统 | 大肥鱼，内置 NapCat | QQ，单独安装 |
| --- | --- | --- |
| Windows 10/11 x64 | [安装程序](https://github.com/SAKURAfan1023/dafeiyu-bot/releases/download/v0.3.0-preview.3/DaFeiYu-0.3.0-preview.3-windows-x64-setup.exe) · [便携 ZIP](https://github.com/SAKURAfan1023/dafeiyu-bot/releases/download/v0.3.0-preview.3/DaFeiYu-0.3.0-preview.3-windows-x64-portable.zip) | [QQ 9.9.33 x64](https://github.com/SAKURAfan1023/dafeiyu-bot/releases/download/v0.3.0-preview.3/QQ_9.9.33_260813_x64_01.exe) |
| Mac Apple Silicon，macOS 14+ | [大肥鱼 DMG](https://github.com/SAKURAfan1023/dafeiyu-bot/releases/download/v0.3.0-preview.3/DaFeiYu-0.3.0-preview.3-macos-arm64.dmg) | [QQ 7.0.0](https://github.com/SAKURAfan1023/dafeiyu-bot/releases/download/v0.3.0-preview.3/QQ_7.0.0_260812_01.dmg) |

1. 先安装 QQ，再安装大肥鱼。Mac 将 QQ 放入 `/Applications/QQ.app`，将 `DaFeiYu.app` 拖入“应用程序”。Windows 另需 [Microsoft Visual C++ x64 运行库](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist)。
2. Windows 从开始菜单选择“打开内置 NapCat”，在打开的目录运行 `launcher-user.bat`（Win10 可用 `launcher-win10-user.bat`），按提示扫码。便携版使用 `Open NapCat.cmd`。
3. Mac 在大肥鱼菜单栏菜单选择“打开内置 NapCat”，在配置工具里切换程序入口为 NapCat、按系统提示授权，再启动并扫码；不用点击下载或更新。
4. 在 NapCat WebUI 创建本机正向 WebSocket 服务，填写 `127.0.0.1:3001`、数组消息格式、强 Token，并开启自身消息上报；在大肥鱼填入同一地址、Token、QQ 号及自己的模型 API Key。连接、选择允许回复的会话，先单次验收，再开始持续运行。

## npm 与 MCP

本次只更新完整客户端的打包方式，npm 模块固定版本仍为 `0.3.0-preview.2`。已准备 QQ / NapCat 的用户可直接运行：

```sh
npx --yes @sakurafan1023/cli@0.3.0-preview.2 setup qq
npx --yes @sakurafan1023/cli@0.3.0-preview.2 qq panel
```

接入 Codex：

```sh
codex mcp add dafeiyu -- npx --yes @sakurafan1023/mcp@0.3.0-preview.2 --modules qq
```

完整客户端也提供包内 MCP 入口，不需额外安装 Node。客户端与 MCP 共享后台；关闭 Host 不会结束独立后台。准备、安装与接入均不会自动登录 QQ 或开始回复。
