# v0.3.0-preview.2 · Windows 原生 QQ、按需安装与 MCP

本次为预览版，提供 Windows x64 和 macOS Apple Silicon 的 QQ 独立模块。CLI、QQ 模块和 MCP 共用版本，npm 安装时自动选择本机后台。既有 macOS 客户端、社交与微信入口保留；微信仍在测试。

## 安装与使用

需要 Node.js 22+ 和 npm。Mac 需要 macOS 14+、arm64；Windows x64 另需 Microsoft Visual C++ x64 运行库。预构建后台无需 Swift、WSL 或虚拟机。QQ、NapCat 和模型服务由用户自行配置；图片功能另需 Python / Pillow。

先安装 QQ 模块，再打开本机 Web 客户端：

```sh
npx --yes @sakurafan1023/cli@0.3.0-preview.2 setup qq
npx --yes @sakurafan1023/cli@0.3.0-preview.2 qq panel
```

需要接入 Codex 时，在完成 QQ 模块安装后运行：

```sh
codex mcp add dafeiyu -- npx --yes @sakurafan1023/mcp@0.3.0-preview.2 --modules qq
```

客户端与 MCP 共享后台、配置及运行状态。安装、打开面板或接入 MCP 不会自动连接 QQ 或开始回复；凭证在本机面板输入。运行前需核对实际账号和允许回复的范围。关闭 MCP Host 后，独立后台仍保留；断开后可用以下命令停止：

```sh
npx --yes @sakurafan1023/cli@0.3.0-preview.2 qq disconnect
npx --yes @sakurafan1023/cli@0.3.0-preview.2 qq stop
```

## npm 与 GitHub 下载

| npm 包 | 用途 |
| --- | --- |
| `@sakurafan1023/cli` | 按需安装和客户端命令 |
| `@sakurafan1023/qq` | QQ 模块和本机后台选择 |
| `@sakurafan1023/mcp` | 本地 stdio MCP，提供 7 个受限工具 |
| `@sakurafan1023/qq-darwin-arm64` | Mac arm64 原生后台及 QQ 资源 |
| `@sakurafan1023/qq-win32-x64` | Windows x64 原生后台、所需 Swift DLL 和 QQ 资源 |

五个包均已发布到 npm，`next` 指向 `0.3.0-preview.2`。请使用上方固定版本或显式 `@next`；这是预览版，默认 `latest` 标签不代表稳定性承诺。Intel Mac、Windows ARM64、Linux npm 原生包尚未发布。

GitHub Release 的五个 `.tgz` 附件与 npm 公共下载逐字节一致，另附 `SHA256SUMS.txt`。它们是 npm 安装包，不是双击安装的桌面应用；普通用户优先使用上方 npm 命令。离线安装时只选择通用三包及本机对应的一个原生包，操作见[QQ 模块说明](https://github.com/SAKURAfan1023/dafeiyu-bot/blob/v0.3.0-preview.2/docs/QQ_MODULES.md)。GitHub 自动生成的 Source code 是完整源码，不是预编译客户端。

## 本次改动

- QQ 从完整应用中独立打包，保留原有文字、群真实 @、记忆、表情、图片、在线工具及定时任务能力，不附带社交浏览器或微信执行模块。
- Windows 原生后台支持本机 Web 客户端及 MCP，处理 Swift SDK、运行库收集、私有文件权限、原子保存和 PowerShell 环境兼容。
- CLI 与 MCP 使用同一后台；写操作校验账号、后台代次和配置版本，超时不自动重提。MCP 不提供任意脚本、任意 OneBot 或直接发送工具。
- 保留第三方原始许可和文件完整性清单；启动已安装后台前核对资源哈希。

## 已验证与边界

- 五个公共 npm 包的版本、平台声明、`next` 标签、文件大小和 SHA-256 均已核对。
- Windows 原生编译、169 项 Swift 测试、9 项 Node 测试、OneBot 合成通信与 HTTP 控制面板均通过。
- Mac arm64 和 Windows x64 均以全新匿名 npm 配置及缓存完成公共 `npx @next` 安装、原生依赖选择、实际 MCP stdio 调用、客户端共享后台及停止检查。Windows 检查移除了 Swift 工具链 PATH。
- Windows 的 QQ / NapCat 兼容按用户确认的社区可用前提接入；本轮未登录真实 Windows QQ 账号，未验证实际扫码和真实消息收发，也未调用真实模型。
- Windows 客户端是本机浏览器界面；本次不提供 Windows 原生图形界面或 MSI 安装器。
