# 真实对话展示与证据边界

![真实 QQ 对话脱敏重排](assets/chat-example.png)

这张图是**真实 QQ 对话的脱敏重排，不是原始 QQ 窗口截图**。所选文字保持原文，中间省略了无关发言；群友 A / B 为匿名代号，不展示原昵称、头像、账号、群名称、群号、消息编号和时间。图中 MSI / S 赛是原讨论里的电竞赛事称呼，不是对用户身份的描述。

取材时以只读 OneBot 群消息历史核对原文，并核对大肥鱼这条回复的消息编号存在于本机机器人已发送消息记录中，避免把账号主人的人工发言当作 AI 回复。原始记录及对应编号只保存在作者本机，不进入公开仓库；公开 HTML 与 PNG 只含上图这三句匿名文字。

这是单个场景的真实例子，不能证明长期稳定性、所有玩笑都能理解，或其他场景的效果。不得以展示图代替新版本验收。
